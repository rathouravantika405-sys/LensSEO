    Important context

    Scores reflect simple on-page readiness rules, not search rankings or the probability of being cited by an AI assistant. A limited crawl cannot prove orphan pages; load time is not a Core Web Vitals metric. Confirm findings before implementation.

    LensSEO · Designed for actionable audits. Powered by evidence, improved by AI.

    How LensSEO works

    1. Enter a public website URL and select a crawl size.
    2. LensSEO reads robots.txt and a bounded sample of HTML pages.
    3. Seven checks identify indexing, content, linking and answer-readiness issues.
    4. Optional competitor heading comparison highlights possible missing sections.
    5. Optional OpenAI analysis drafts titles, metas and short answers for your review.
    6. Download the exact five-column CSV action list or a full JSON report.

    The audit is a bounded HTML sample; AI scores are not measurements of real citation likelihood. For a section URL such as /neet, section-only scanning is on by default.
